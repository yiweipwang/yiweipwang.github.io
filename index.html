Selected work

roughly, my favorites first
  • 01

    Volatility dispersion backtest

    A Python backtest of volatility dispersion: sell index volatility, buy the constituents, and capture the correlation premium. I built the variance-swap pricing, cost model, and reproducibility checks from scratch, without a backtesting library.

    2026 · quant finance · Python
  • 02

    EMA crossover momentum strategy

    A long/short EMA crossover momentum strategy backtested on ten years of minute-by-minute AAPL data, with slippage and commissions modeled. Resamples to any timeframe and outputs a full set of performance metrics and charts.

    2026 · quant finance · Python / pandas
  • 03

    Tilings of hexagonal boards

    I extended the classic Fibonacci tiling problem to hexagonal strips, derived the recurrence, and published the resulting integer sequence in the OEIS as A365352.

    2023 · combinatorics · OEIS A365352
  • 04

    Minesweeper, with an AI opponent

    A full Minesweeper implementation with a tutorial mode, a hint engine, and an AI opponent that uses BFS flood reveal plus a probability tree over the frontier to pick the safest unopened cell.

    2024 · game + AI · Java / JavaFX
  • 05

    Sound Space, rebuilt in JavaFX

    A rhythm game whose chart is generated from the audio. A Python beat-detection pipeline analyzes any song and emits a note chart, which the game plays back in sync with the music.

    2024 · game + audio · Java / Python
  • 06

    Smartphones and adolescent sleep

    A literature review of how nighttime phone use affects adolescent sleep, focused on which specific usage behaviors predict poor sleep quality.

    2023 · health research · data analysis
About

A short background

My favorite projects live on the seam between math and code. A tiling problem becomes a recursion; the recursion becomes an algorithm — and then it has to survive contact with something real, like a rhythm game reading beats off an audio file in real time.

Most days that means Python and Java, plus MATLAB and LaTeX when the math gets heavy and enough JavaScript to be dangerous on the web. When I'm not building something, I'm probably three neighborhoods away chasing down a restaurant someone swore by.
